About Me

I am a B.Sc. Physics student with interests in astrophysics, observational astronomy, scientific visualization, and data-driven scientific analysis.

My work focuses on combining computational methods with astronomy and physics research — from exoplanet detection and galaxy cluster dynamics to real-time tracking systems and image-based experimental analysis.

Beyond science, I enjoy poetry, creative storytelling, design, and interdisciplinary thinking.

Featured Projects

Detecting Exoplanets using Radial Velocity

Developed and validated a radial velocity analysis pipeline using synthetic Keplerian models and Lomb–Scargle periodograms to characterize the exoplanet 51 Pegasi b.

Galaxy Cluster Dynamical Mass Estimation

Utilizing Sloan Digital Sky Survey (SDSS) spectroscopic data to identify cluster member galaxies, calculate velocity dispersion, and estimate total dynamical mass.

Real-Time ISS Tracker

Building a real-time International Space Station tracker using Python and astronomy APIs.

Surface Tension using FIJI

Experimental physics project involving image processing and scientific measurement using FIJI software.

Halo CME Detection using Aditya-L1 Data

ISRO Bharatiya Antariksh Hackathon project focused on identifying halo CME events using SWIS-ASPEX payload particle data.
